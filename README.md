# Dashboard V22

A responsive glassmorphism productivity dashboard built with React, Vite, Tailwind CSS, and Recharts.

## Features
- Overview and analytics
- Employee management
- Attendance check-in/check-out demo
- Task management
- Saved items
- Dark/light theme
- Local storage persistence
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Deploys to GitHub Pages using the workflow in `.github/workflows/deploy.yml`.
